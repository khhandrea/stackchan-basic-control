# StackChan Basic Control

Documentation and firmware for an M5Stack StackChan (SKU K151) controlled from a Raspberry Pi 3 over USB serial.

## Layout

- `documents/`: Hardware, interfaces, factory firmware and measured device values
- `firmwares/general/`: StackChan basic program for control and monitoring
- `host/`: Host client (Python, uv) run on the Raspberry Pi
