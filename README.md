# StackChan

Documentation and firmware for an M5Stack StackChan (SKU K151) controlled from a Raspberry Pi 3 over USB serial.

## Layout

| Path | Description |
|---|---|
| [documents/](documents/) | Hardware, interfaces, factory firmware and measured device values |
| [firmwares/general/](firmwares/general/) | StackChan general firmware: capabilities ([README](firmwares/general/README.md)) and serial protocol ([PROTOCOL](firmwares/general/PROTOCOL.md)) |
| [host/](host/) | Host client (Python, uv) run on the Raspberry Pi |
